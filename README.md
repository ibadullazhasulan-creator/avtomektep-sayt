# COBALT 3D LAB — Chevrolet Cobalt интерактивті 3D атласы

Қазақ тіліндегі оқу мақсатындағы Three.js веб-сайт. Көлікті айналдыру, ішіне үңілу, бөлшектерді іздеу, таңдау, жақындату, капот/есік/жүксалғыш ашу, рентген және жүйелерді бөлшектеу режимдері бар.

**Ескерту:** машина, қозғалтқыш, салон және бөлшектер компьютерлік кодпен салынған **стильденген оқу моделі**. Бұл зауыттың инженерлік дәл CAD файлы, нақты жөндеу сызбасы немесе барлық 10 000+ бөлшектің толық геометриясы емес. Геометриялық үлестер кей жерде шартты берілген. Сайттағы мәліметтің бір бөлігі белгілі комплектацияларға тән; нақты көлік VIN / жылына қарай өзгереді.

## 1. VS Code-та қосу

1. `COBALT_3D_LAB` қалтасын ашыңыз (`File → Open Folder`).
2. VS Code extensions ішінен **Live Server** кеңейтімін орнатыңыз.
3. `index.html` файлын оң жақпен басып **Open with Live Server** таңдаңыз.
4. Немесе Windows-та Python орнатылған болса, `start_windows.bat` файлын екі рет басып сайтты ашыңыз.
5. Сайт браузерде әдетте `http://127.0.0.1:5500/` мекенжайында ашылады.

**Маңызды:** HTML файлын `file://` арқылы тікелей ашпаңыз; ES modules үшін жергілікті HTTP сервер керек. Интернет қажет, себебі Three.js және қаріптер CDN арқылы жүктеледі.

Егер Live Server қолданғыңыз келмесе, Python орнатылған жағдайда терминалда:

```bash
cd COBALT_3D_LAB
python -m http.server 8000
```

Сосын `http://localhost:8000` ашыңыз. npm орнату міндетті емес.

## 2. GitHub-қа жариялау

1. GitHub-та жаңа ашық `cobalt-3d-lab` репозиторийін құрыңыз.
2. VS Code терминалында:

```bash
git init
git add .
git commit -m "Initial COBALT 3D LAB"
git branch -M main
git remote add origin https://github.com/USERNAME/cobalt-3d-lab.git
git push -u origin main
```

`USERNAME` орнына өз GitHub логиніңізді енгізіңіз.

3. GitHub-та репозиторий → **Settings → Pages → Build and deployment** бөлімінен **Deploy from a branch** таңдаңыз.
4. Branch = **main**, Folder = **/(root)**, **Save** басыңыз.
5. Жарияланған мекенжай: `https://USERNAME.github.io/cobalt-3d-lab/` (GitHub жариялауды аяқтағаннан кейін).

## 5. Өзгерту

- **Жаңа бөлшек:** `src/data.js` ішіндегі `PARTS` тізіміне `p(...)` жазбасын қосыңыз, координатын анықтаңыз. Қажет болса `src/car.js` файлына оның 3D геометриясын жасаңыз.
- **Кузов:** `src/car.js` ішіндегі `buildExterior()` функциясын өзгертіңіз.
- **Түстер:** `src/styles.css` ішіндегі `:root` айнымалылары.
- **Көлікті шынайы фотограмметриялық 3D үлгіге ауыстыру:** лицензияланған `.glb` файлын жүктеп, Three.js `GLTFLoader` пайдаланып `src/car.js` процедуралық моделін алмастыруға болады. Нақты детализация үшін осындай модель қажет.
